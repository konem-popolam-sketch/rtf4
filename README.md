# Русская Рыбалка 4 — браузерный ремейк

Фанатская реализация в браузере: 3D-сцена на three.js, симуляция заброса, поклёвки и
вываживания рыбы, снасти, наживки, водоёмы, погода, квесты и магазин. Всё на чистом ESM
без сборки — открывается статикой как есть.

**Играть: https://konem-popolam-sketch.github.io/rtf4/**

## Что внутри

- `index.html` — единственная страница, importmap на локальный three.js
- `src/core/` — шина событий, ГПСЧ, утилиты, хранилище, игровой цикл
- `src/data/` — рыбы, наживки, приманки, снасти, водоёмы, погода, квесты
- `src/sim/` — физика заброса, поклёвки, вываживания, климат, агрегация снасти
- `src/scene/` — рендерер, вода, берег, удочка, рыба, эффекты
- `src/ui/` — HUD и семь панелей (карта, снасти, инвентарь, магазин, атлас, квесты, настройки)
- `src/audio/` — весь звук синтезируется на WebAudio, файлов нет
- `vendor/three.module.js` — three.js r169

## Запуск локально

```bash
node tools/serve.cjs 8080 .
```

Открыть <http://127.0.0.1:8080/>.

Ассеты не нужны: текстуры рисуются процедурно на canvas, звук — осцилляторами.

## Проверка

```bash
node tools/check-all.mjs   # синтаксис, импорты, правила SPEC
node tools/selftest.mjs    # автотесты логики
```

## Публикация

Статика раздаётся напрямую из корня репозитория через GitHub Pages (ветка `main`, путь `/`).
`.nojekyll` отключает обработку Jekyll, чтобы файлы отдавались как есть.

## Правовой статус

Некоммерческий фанатский проект. «Русская Рыбалка» — товарный знак соответствующих
правообладателей; здесь нет ни одного их файла: вся графика процедурная, весь звук
синтезируется, названия и данные написаны заново.
